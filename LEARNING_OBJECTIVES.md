## Workshop Learning Outcomes

By the end of the workshop, attendees should be able to:

1. Understand the AI agent loop: Explain how an agent reasons, calls tools, and processes observations.
2. Implement task delegation: Build a `delegate()` function that assigns bounded tasks to specialist agents with isolated context and tools.
3. Verify and merge agent findings: Validate specialist claims against evidence, identify contradictions, and consolidate findings into a reliable assessment.
4. Enforce human oversight: Implement an approval boundary that prevents agents from executing consequential actions without explicit human authorization.
